# 项目测试

使用主环境运行项目自有测试，不收集第三方仓库的测试：

```bash
conda run -n aiaa3201 python -m pytest -q
```

测试覆盖数据/split、输出schema、经典双目定点与单位转换、全GT域指标与选参、左右一致性、原始数组重算、NYUv2两模型协议、官方边界指标和静态尺度分析，以及DA/VDA指定片段的同帧输入、官方窗口、relative有效值、固定显示与来源/产物篡改。

`test_stereo_coverage_study.py`覆盖开发/保留隔离、两种冻结规则、区域分母/空值、60份合成预测及篡改重封装拒绝。

`test_part3_bc.py`覆盖：

- B完整795图全局尺度公式、范围与无效值、小子集禁止冻结。
- 合成开发预测→固定尺度→RAW/B测试→数组/GT分数重算。
- 开发预测身份/来源篡改拒绝，输出目录禁止覆盖。
- C源码来源与CPU/main逐值一致、孔洞保留、三个方法的CPU/CUDA数值一致。
- RAW/C/去RGB/去深度门控的合成运行、场景配对统计和保存数组重算。
- 小样本`formal_complete:false`以及外层SHA重新封装后仍拒绝被篡改的C预测。

CUDA测试先检查实际可用性，不可用则跳过并如实记录。合成网络和小数据不加载基础模型、不训练，不能作为完整真实数据改进的证据。最新实际数量与范围见[implemented.md](../implemented.md)，正式B/C门禁见[Step B](../docs/stepB.md)、[Step C](../docs/stepC.md)。

`test_part3_studies.py`覆盖11项：验证图像等权的加权中位数AbsRel最优性、两种log目标差异、795图合成完整拟合/重算、Guided Filter与独立逐窗口回归一致、纹理掩码/空域N/A、固定GT剖面对模糊的响应和共同可测覆盖、六方法运行/核验、不可覆盖、小子集门禁、原源码集合不变及重封装SHA后仍拒绝错误经典预测。2026-11-06全项目为349 passed，14个既有弃用告警；不替代正式实验成绩。
