# Step 6：应用、报告与最终提交

## 当前状态

尚未完成。Part 1/2现有实验结果与70帧视频比较可用于准备材料；Part 3的[B全局尺度](stepB.md)和[C边缘感知细化](stepC.md)正式静态结果与分析已具备，全量核验报告留存情况见对应页面。课程100帧素材问题仍需单独确认。

## 应用Demo

用提供的NYUv2图像展示RGB、固定米制范围深度和一种简单应用，优先同设置RAW/C背景虚化，或点云/点击查看深度。两方法使用相同图像、对焦距离、模糊强度及输出尺寸，不能通过改变显示参数制造改进。

若使用预测或近似内参，说明来源与分辨率；轴向深度Z和到相机光心的欧氏距离区分。没有独立实际测量，不宣称真实卷尺测距精度或避障F1。GT只作离线评分，不进入测试图尺度拟合。

## 报告

报告使用CVPR模板，6–8页、不计参考文献。包含经典双目MAE/覆盖率与泛化、两模型原生米制、指定片段同帧视频比较、B/C实际方法/结果/代价、两项C消融、场景统计和三项真实困难案例。

B使用795张开发GT拟合一个尺度，必须与Part 2 untouched native metric区分；C固定后处理，不训练。未运行的B+C、跨域或视频方法改进不能写为已完成。保留负结果，不用更平滑的图像替代准确率证据。基础模型推理与后处理效率分开报告硬件、尺寸、精度及峰值显存。

- `depth_results.zip`中的浮点预测、索引/manifest、配置、环境、指标、视频和校验值。

应先确认课程是否接受70帧完整素材或提供更长版本；不重复帧、插帧或改变帧率冒充100帧。Demo、报告、公开复现与提交各有独立门禁，未完成前不勾选。
