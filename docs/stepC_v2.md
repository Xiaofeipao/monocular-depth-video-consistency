# Direction C v2：受控去噪与边界收窄

## 基本信息与状态

目标是同时改善官方SI boundary F1和真实的边界形状：过渡更窄、位置不变差、少漏边，同时控制纹理伪边与米制误差。SI提高并不自动代表锐化成功。现有C及其全部结果保持原位，见[Step C](stepC.md)；B保持不变，v2也不组合B的尺度。

两模型完整开发、验证、冻结、654图七方法比较和四份完整数值重放报告均已完成。**v2相对原C明显缩小边界宽度；Depth Pro的SI也提高，UniDepth的SI略降；两模型仍未比RAW更窄。** 正式结果与收益/代价见下文，早期两图工程检查单独保留，不替代正式成绩。实现阶段359项测试通过，本次未重复运行测试或长实验。

本任务符合课程Direction C使用RGB线索细化深度不连续边界、避免纹理复制的要求。算法无学习权重、不训练，复用已有原生预测；全部长时运行由用户启动。

## 方法：先去噪，再有条件地收窄过渡

现有C对邻域逆深度加权平均，能抑制局部噪声，但两模型正式结果的共同剖面都比RAW宽约0.56/0.59像素。v2增加主动收窄步骤：

1. 计算原C的固定联合滤波结果。在log-depth中，以0.5或1.0的比例与RAW混合，得到去噪初值。
2. 根据初值的梯度估计深度边界法向，在法向两侧约6像素处检查深度差，并用更外侧位置检查两侧是否稳定。只处理深度本身支持的两层过渡，减少把斜坡或RGB纹理当成物体边界的机会。
3. 检查RGB梯度是否沿深度法向变化，以及两侧颜色是否存在差异。RGB提供支持，不直接把颜色值转换成深度。
4. 使用深度法向曲率确定向近侧或远侧收缩的方向，通过一像素邻域的定向侵蚀/膨胀逐步收窄过渡。曲率符号与支持权重连续变化，避免硬开关产生新的像素跳变。
5. 每一步都限制在RAW的局部深度包络及`log(RAW) ± 0.04`内。对应单像素深度约为RAW的0.961–1.041倍；这是改动限幅，不是深度准确率保证，也不是课程评分裁剪。

这是受经典[Osher–Rudin shock filter](https://epubs.siam.org/doi/abs/10.1137/0727053)启发的项目自有受控变体，不宣称复现原论文PDE离散解。预测函数只接收RGB、原生深度和固定参数，不读取GT、语义标注或另一模型。开发集GT只参与离线选参和评价。

固定步长0.15、导数平滑σ=0.8、双侧支撑半径6、最小两侧深度比1.10、外侧不稳定度比例0.15、RGB梯度尺度0.03。邻域包络使用13×13，额外检查外侧两像素。处理不补洞、不做测试GT对齐；图像外圈不执行收窄，但仍有初值去噪。

限幅能控制过冲，但不能保证每处边界都更准确。预测中的伪结构、RGB/深度错位、低对比物体、细结构和遮挡边界仍可能失败；平滑与锐化也可能存在指标取舍。

## 统一实验与开发协议

两模型使用同一实现、同一开发图、场景划分、评价定义、候选集合和选参规则，各自选参数，然后固定参数评价。不是先在一个模型上调好再直接当作另一个模型的最优设置。

官方795张`trainNdxs`只用于开发，654张`testNdxs`只用于冻结后的报告。开发/测试场景无交集；开发内部按scene划分：

| 子集 | 图数 | 场景数 | 用途 |
|---|---:|---:|---|
| tune | 636 | 199 | 比较六组候选并选择参数 |
| validation | 159 | 50 | 检查已选定方法，不重新选参 |
| test | 654 | 215 | 参数冻结后报告完整正式效果 |

场景使用配置中的固定seed与scene字符串SHA256排序。工程检查已查看`office_0003`的两张图，因此这个scene明确保留在tune；它不进入validation。其余开发scene按固定排序分配。相同场景的图不会分散到两组中。

前期C测试结果已被查看，v2的设计受到这些发现启发。因此，即使选参严格使用开发集，654图仍属于该划分上的探索性方法比较，不称为全新、从未被查看的最终确认。v2不能据测试结果继续挑候选或改评价器。

课程协议不变：480×640完整预测；评分crop为`[45:471,41:601]`，有效GT为`0.001 < depth < 10 m`；米制评分按课程裁剪预测、图像等权，`alignment:none`。官方SI调用原有Depth Pro实现及1.05–1.25的10阈值。定位、剖面和纹理诊断使用未裁剪数组，复用原配置与同一GT支持，不通过放宽阈值制造提升。

### 六组候选与选参

候选只有两个变化维度，其余参数固定：

| 候选ID | 去噪混合比例 | 收窄迭代数 |
|---|---:|---:|
| blend050_steps1 | 0.5 | 1 |
| blend050_steps3 | 0.5 | 3 |
| blend050_steps5 | 0.5 | 5 |
| blend100_steps1 | 1.0 | 1 |
| blend100_steps3 | 1.0 | 3 |
| blend100_steps5 | 1.0 | 5 |

先在tune比较四项：官方SI越高越好、1.05/1px容差F1越高越好、10%–90%过渡宽度越低越好、纹理平坦区伪边代理越低越好。四项分别排序，同值同名次，名次和最低者入选；并列时先选SI较高者，再按候选ID排序。名次相加避免把像素宽度和F1直接混成有任意单位的分数，但它仍是预先声明的折中规则，不保证四项同时改善。

宽度排序使用RAW与全部六候选**共同可测的同一组GT固定剖面**，先图内平均，再图像等权，并记录覆盖。若没有共同可测剖面，停止选参，不伪造宽度。纹理空域保持N/A。

选定结果先写入`selection_before_validation.json`，然后才运行validation。验证不换候选，也不把失败结果替换成RAW；`freeze`保存实际选中的参数及验证状态。方法结果是否达到研究目标，与它是否获得完整运行记录分开判断。

### 正式七方法

| 方法 | 参数与用途 |
|---|---|
| RAW | Part 2A原生米制预测，只读复用 |
| C | 原固定联合滤波，读取原C正式数组和计时 |
| Gaussian_log | 原固定经典对照，只读复用 |
| RGB_guided_log | 原固定经典对照，只读复用 |
| C_v2 | 本模型开发集选定参数的完整v2 |
| C_v2_no_sharpen | 相同参数与限幅，仅去掉定向收窄，保留去噪初值 |

最后一个消融不是“整条算法完全不用RGB”，用于回答新增的RGB支持是否有帮助。三个v2方法都保存真实数组，不使用RAW替换。早期工程检查展示五方法；当前正式测试已包含两个经典对照，共七方法。

## 怎样判断是否真正更好

先看`summary.json`的官方八指标、`paired_scene_deltas`（相对RAW）、`paired_scene_deltas_vs_C`（相对原C）。再看`all_methods_common_profiles`：七方法使用同一批可测剖面，图内平均后按图等权，并按scene成簇给区间；必须同时写覆盖图数/剖面数。空域、弱对比、歧义和深度顺序错误保留，不当作宽度为0。

判断“SI提高且锐化更好”至少需要：

- 相对RAW和原C的官方SI变化与配对区间。
- 相同支持上的10%–90%宽度更窄，同时中心位置误差、边缘距离和边缘召回没有明显代价；不能只把过渡压窄到错误位置。
- RGB纹理平坦区伪边代理、低纹理对照和过冲没有明显恶化，AbsRel/RMSE等米制指标保持可接受。
- 在相同坐标、相同剖面和同一边缘定义下查看实际案例；列出失败图，不能只展示最好的一张。

`mean_targets`只记录SI与宽度均值方向，不是自动验收器。研究可完整运行但未达到同时改善的目标；这种结果应保留真实方法，不替换RAW、不改阈值。当前v2使用CPU，原C计时来自其原始CPU/CUDA后端；不能把这些不同后端的计时直接当成公平算法加速比。

### 消融：主动收窄有效，新增RGB支持没有全面优势

去掉收窄时，v2保留相同混合、初值与限幅。加入收窄后，SI增加0.00848245/0.00300937，区间分别[0.00695091, 0.01007479]/[0.00183659, 0.00417416]；共同宽度减少0.13250/0.15635像素，区间全负。因此收窄步骤确实有作用，不只是把去噪强度从1降成0.5后改名字。

相对原C的全部宽度变化也不能都归功于收窄：去收窄版本自身已比原C窄约0.29244/0.31341像素，其后再由收窄步骤减少0.13250/0.15635像素。收窄同时让AbsRel增加约0.00002632/0.00002560；UniDepth的剖面中心误差也比去收窄版本高0.02114像素，区间[0.01181, 0.03110]。这是实际取舍。

去掉新增RGB支持后，Depth Pro的SI略高于完整v2约0.00047691，完整法减消融的区间为[-0.00071942, -0.00024933]；UniDepth的SI差区间跨零。去RGB支持也让宽度再窄约0.02173/0.01895像素、容差F1略高。完整法的AbsRel则分别低约0.00000499/0.00000307，保留了少量米制精度。新增RGB支持没有在SI、宽度和纹理代理上展示全面优势，不能强行解释为必要模块；这也不等于算法完全不需要RGB，因为该消融的原C初值仍使用RGB。不依据这次test结果更换冻结方法。
