## Part 3 contributions and observed limits

- **A — flow-guided temporal fusion:** inverse-depth history with consistency,
  photometric, depth and edge gates; A0–A6 ablations remain available. TUM flow
  temporal log-error drops 0.024261 → 0.021797 (10.2%); delta1 loses 0.373
  percentage points. Current constrained choice on this short sequence.
- **B — independent metric calibration:** robust fixed scale from separately
  measured development landmarks; rejects test-frame overlap. Contributes scale
  correction rather than temporal smoothing. Real comparison skipped because
  independent measurements are absent; synthetic recovery is not real accuracy.
- **C — edge-aware spatial refinement:** RGB/log-depth bilateral weighting in
  inverse depth. TUM AbsRel 0.285482 → 0.285366, temporal error → 0.023987.
  Tiny changes on sixteen correlated frames do not establish superiority.
- **D — uncertainty-weighted temporal fusion:** local residual variance or
  supplied log-depth variance controls history weight. TUM temporal error
  0.021343 is lowest, but delta1 loses 0.774 points, exceeding the 0.5-point
  accuracy guard. This negative result is retained; heuristic variance is not
  calibrated model uncertainty.
- **E — reduced/adaptive optical flow:** reduces postprocessing cost while
  keeping full-resolution depth. Both variants are retained. This accelerates
  flow, not the foundation model; comparisons include flow time and warmup.
- **F — obstacle warning:** ROI near-depth percentile, confirmation and
  hysteresis turn depth into an application output. Depth arrays remain RAW.
  Warning accuracy is unavailable on the present TUM ROI because GT has holes.
- **B+C+D combination:** preserves the compositional experiment; skipped on
  real runs without independent calibration rather than fitting test GT.

Selection enforces AbsRel ≤ RAW+0.01, delta1 ≥ RAW−0.005 and edge F1 ≥ RAW−0.01.
Tokyo examples lack GT; their temporal proxy alone cannot select the most
accurate method. TUM covers only 1.70 seconds. All original methods, comparisons
and negative results are retained for subsequent optimization.
