## 同帧模型对照

使用官方 DAV2-Small 与 VDA-Small 相对模型，CPU FP32；共同保存的 RGB 长边
448，网络 input-size 252。每段取中间 16 帧、5 FPS，覆盖约 3 秒。
这是低分辨率短片段预检，没有运行训练或完整视频评测。

以下为光流 warp 绝对误差除以各模型固定首帧 P95-P5 范围，越低越好。
使用共同的前后向一致性掩码（阈值 1 像素），没有逐帧尺度对齐：

- 横屏静态，9.67–12.67 秒：DAV2 **0.00361107**，VDA **0.00136544**，降低 **62.2%**。
- 竖屏静态，6.67–9.67 秒：DAV2 **0.00112984**，VDA **0.00046354**，降低 **59.0%**。
- 相机移动，11.29–14.31 秒：DAV2 **0.01864598**，VDA **0.01344347**，降低 **27.9%**。
- 人物走动，7.43–10.43 秒：DAV2 **0.00585487**，VDA **0.00331880**，降低 **43.3%**。

两者均能恢复桌椅、地面、背景的主要层次，人物轮廓也可辨认；细椅条、椅腿及
人物与椅子交叠处仍有粘连或细节丢失。VDA 在所测片段的时序误差均较低，
但平滑本身也可能降低分数，不能据此认定边界精度或米制距离更准确。
人物没有做分割，动态区和光流误差也会影响分数；不同场景间不直接排名。

默认 16 帧会触发官方 VDA 的 32 帧窗口末帧填充，没有覆盖跨窗口衔接。
后续需以完整视频、更高输入分辨率检验运动后半段、人物进出及遮挡恢复。
没有深度/位姿 GT，无法严格验证米制精度或把真实距离变化直接解释为尺度漂移。

## 复现与本地结果

在项目根目录运行（已安装项目依赖、源码及本地权重）：

```powershell
. ./scripts/project_cache.ps1
python scripts/review_capture.py --models
```

输出位于 `outputs/self_recorded_review/`：`capture_checks.json`、`model_checks.json`、
`commands.json`、`review.md`，以及每段的原始预测、RGB、有效掩码、配置、环境、
计时、源文件 SHA256、实际采样时间、逐对 CSV、flow/mask 与比较视频。
旧入口 `outputs/self_recorded_review/review_capture.py` 转到维护中的新脚本。
更改素材、采样或模型设置时应通过 `--output` 指定新目录。

每段 `comparison.mp4` 左到右为 RGB / DAV2 / VDA，相对逆深度暖色表示更近。
两模型各用首帧 P5/P95 做固定显示校准，整个片段不变；只校准显示，不修改原始
NPY，也不把颜色解释为米数。主入口自带的各模型原始范围视频与该比较视频分开保存。
