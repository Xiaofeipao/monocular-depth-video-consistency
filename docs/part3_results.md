# Part 3：探索结果与方向选择

## 主方向：C 边缘细化

当前选择 C 为主探索，C_cuda 为保持同一公式的 GPU 实现。使用固定 5×5
RGB/log-depth 联合权重与逆深度平均；不在测试集搜索参数，不做 GT 尺度拟合。
两条基线均按相同 NYUv2 654 图、完整 RGB、crop、有效深度范围与代码评分：

- Depth Pro：AbsRel 0.100473264 → 0.100366985，RMSE 0.392219569 →
  0.391542824 m，δ1 0.915185154 → 0.915454328；官方 SI Boundary F1
  0.159268547 → 0.171106615，相对提高约 7.4%。
- UniDepthV2-S：AbsRel 0.114541365 → 0.114427372，RMSE 0.398820607 →
  0.398034681 m，δ1 0.892364681 → 0.892600532；SI Boundary F1
  0.113009609 → 0.122560834，相对提高约 8.5%。

主要收益在边界质量；按 215 个场景进行的配对 bootstrap 支持本划分内的边界增益，
但不能声称跨域最优，也不能据此推断时序改善。距离精度提升幅度很小。
完整论文协议审查与统计限制见 [逐篇比较](paper_comparison.md)。
完整逐图证据在 `evidence/full_benchmark_20261029/`，基线和细化结果分别报告。

## 计算效率

C_cuda 保留原 C 的完整邻域、FP32、分辨率和无效区；两段测试中后处理速度
为 3.80 → 91.24 FPS、4.01 → 90.29 FPS，约加速 24.0 倍和 22.5 倍，
包含设备传输，最大相对数值差小于 8.4e-7。该比值对应固定 CPU 单线程对照，
不是基础模型或整套系统加速。证据见 `evidence/cuda_20261029/`。

## 时序补充及其他方向

- 以下短片结果为早期探索，最新多序列结论见后文和 [D 研究](d_research.md)，不得当作全部实验证据。
- A：短 TUM 序列时序 log-error 0.024261 → 0.021797，改善约 10.2%；
  δ1 损失 0.373 个百分点，通过精度约束。但只有 16 帧、约 1.70 秒，
  后续自录复核见下文。适合作为时序补充，当前证据规模小于 C。
- B：外部测点版本继续保留；新增官方 795 张开发图拟合一个全局尺度，冻结后评价
  654 张测试图。Depth Pro/UniDepth AbsRel 分别降至 0.096599796/0.102022244；
  详见 [开发集全局尺度实验](global_scale_study.md)。这是使用开发标注的域内校准，
  不属于 untouched 零样本结果，也未验证跨域收益或 B+C 组合。
- C_fast：缩小邻域会损伤边缘表现；C_cuda 保留完整公式，作为推荐实现。
- D：早期短视频时序误差较低，但精度损失超标；后续冻结多序列 D 已通过 3/3 约束，
  仍不替代 C 的图像主线。
  局部残差方差是启发式估计，不能称为已校准的模型不确定性。
- E：半分辨率光流在短序列的独立位姿评分中最优且通过精度约束；这是后处理
  效率/时序补充，尚未实现基础模型 ONNX 或量化部署。
- F：预警、滞回和缺测处理可运行，缺完整应用 GT，尚无可靠应用 F1。
- B+C+D：没有独立标定数据时跳过。各方向代码、消融与负结果保留供对照。

证据见 `evidence/optimization_20261028/`；光流评分与位姿评分的排序不同，
因此不宣布跨场景、跨指标通用的最好方法。

## 复现入口

自录四段的 CPU 同帧对照已完成：独立 RAFT 评分下 A、C、D、E_half 的时序误差
分别降低约 8.6–13.6%、1.8–4.9%、12.6–17.0%、8.4–13.5%。
E_half 是当前 CPU 视频的效率/时序折中；D 时序分数最低，但无 GT，不能认定其
通过精度约束。C 的主推荐依据仍是完整 NYUv2 的边界评测。
运动段的 warp 残差还包含真实深度变化，不能直接等同纯闪烁或论文 TAE；
RAFT 评分只提供独立光流后端，不消除这项几何限制。
协议、结构诊断和限制见 [自录视频 Part 3 对照](self_recorded_part3.md)。

图像全量基准：`scripts/run_full_image_benchmarks.ps1`；
单独细化：`scripts/evaluate_nyuv2_refinement.py`；
视频对照：`pipelines/part3/compare_directions.py`；
加速对照：`scripts/benchmark_part3_cuda.py`。

## 扩展验证的适用边界

四段自录视频各 64 帧与 TUM 两段 64/54 帧的固定参数结果见
[扩展验证](extended_validation.md)，更高输入分辨率见
[同帧分辨率检查](video_resolution_comparison.md)。252 输入的两段 GT 样本中，
D 均通过精度/边界约束且 pose-log-error 最低；此前短片段的负结果仍保留。

iBims 100 图的处理版反例进一步限制 C 的推荐范围：Depth Pro 的 masked ratio SI F1
下降约 9.50%，UniDepthV2-S 则提高约 2.57%。两者距离精度变化都很小。
C 的主贡献应表述为冻结 NYUv2 协议内的边界收益，不能宣称普遍跨域改善。
新增实验保持固定参数，没有依据测试集挑选更好的参数来替换负结果。

518 同帧组中，D 在两个 TUM 样本仍通过精度/边界约束，pose-log-error
降低约 2.50% / 6.30%；C 的 log-edge F1 两段均退化超过 0.01，未通过约束。
四段自录视频中 D 的独立 RAFT proxy 降幅约 10.98–16.91%，E_half 约 8.06–14.21%。
时序候选优先继续验证 D；算力折中保留 E_half；C 的推荐限定在已经验证的图像协议。
这不是 D 的跨场景最优证明，也不构成对 VDA 论文原始 TAE 的复现。

## D 的多序列与机制研究

使用 desk 开发组选参，冻结后在 rpy、sitting_static、walking_xyz 三条新序列
测试；另保留四段自录视频和 xyz 两段参考。完整协议与消融见
[D 多序列研究](d_research.md)。

- 完整 D 的 pose-log-error 降低约 0.95%、14.27%、5.19%，三段均通过精度/边界约束。
- E_half 对应降低约 0.98%、11.96%、5.66%，也通过三段约束；D 并非逐段最优。
- 固定权重 D_temporal 分别降低约 1.56%、23.12%、8.70%，但静态人物段边界 F1
  从 0.580940 降至 0.569460，超过预设 0.01 退化上限，仅通过两段约束。
- 启发式置信度版的价值体现为本轮更保守的折中，不能宣称其时序分数必然更好，
  也不能把启发式方差当作论文的学习式、已校准模型不确定性。
- 开发组选择的低覆盖重置配置在三条新测试序列与原始 D 预测相同，未获得新增收益。
  C 在三条新测试序列仅通过一段边界/精度约束，继续保留为受协议限制的图像方向。

固定权重与可变权重的比较也改变了实际平滑强度；自然序列中未触发重置的情况
不能用来证明重置的有效性。序列数量少且可能共享环境，不作跨域最优或帧级显著性结论。

文件管线实测中，E_half 比 A 的吞吐提高约 15.8% / 25.2%，仍慢于 RAW。
观感抽查、边界带/新显露区域诊断、相机敏感性和采用建议见
[研究复核](d_research_review.md)。视频默认折中优先考虑 E_half，D 保留为时序优先选项；
C 的主要推荐范围仍限于已验证的图像协议。
