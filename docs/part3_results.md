# Part 3：探索结果与方向选择

## 主方向：C 边缘细化

当前选择 C 为主探索，C_cuda 为保持同一公式的 GPU 实现。使用固定 5×5
RGB/log-depth 联合权重与逆深度平均；不在测试集搜索参数，不做 GT 尺度拟合。
两条基线均按相同 NYUv2 654 图、完整 RGB、crop、有效深度范围与代码评分：

- Depth Pro：AbsRel 0.100473264 → 0.100366985，RMSE 0.392219569 →
  0.391542824 m，δ1 0.915185154 → 0.915454328；官方 SI Boundary F1
  0.159268547 → 0.171106615，相对提高约 7.4%。
- UniDepthV2-S：AbsRel 0.114541365 → 0.114427372，RMSE 0.398820607 →
  0.398034681 m，δ1 0.892364681 → 0.892600532；SI Boundary F1
  0.113009609 → 0.122560834，相对提高约 8.5%。

主要收益在边界质量；不能声称跨域最优或统计显著，也不能据此推断时序改善。
完整逐图证据在 `evidence/full_benchmark_20261029/`，基线和细化结果分别报告。

## 计算效率

C_cuda 保留原 C 的完整邻域、FP32、分辨率和无效区；两段测试中后处理速度
为 3.80 → 91.24 FPS、4.01 → 90.29 FPS，约加速 24.0 倍和 22.5 倍，
包含设备传输，最大相对数值差小于 8.4e-7。该比值对应固定 CPU 单线程对照，
不是基础模型或整套系统加速。证据见 `evidence/cuda_20261029/`。

## 时序补充及其他方向

- A：短 TUM 序列时序 log-error 0.024261 → 0.021797，改善约 10.2%；
  δ1 损失 0.373 个百分点，通过精度约束。但只有 16 帧、约 1.70 秒，
  需要自录视频复核。适合作为时序补充，当前证据规模小于 C。
- B：实现独立测点尺度标定，拒绝测试帧重叠和重复地标。缺少实测标定点，
  暂不能判断真实收益；以 C 为主方向时无需专门补标定数据。
- C_fast：缩小邻域会损伤边缘表现；C_cuda 保留完整公式，作为推荐实现。
- D：短视频时序误差较低，但精度损失超标，暂不推荐为主方向。
  局部残差方差是启发式估计，不能称为已校准的模型不确定性。
- E：半分辨率光流在短序列的独立位姿评分中最优且通过精度约束；这是后处理
  效率/时序补充，尚未实现基础模型 ONNX 或量化部署。
- F：预警、滞回和缺测处理可运行，缺完整应用 GT，尚无可靠应用 F1。
- B+C+D：没有独立标定数据时跳过。各方向代码、消融与负结果保留供对照。

证据见 `evidence/optimization_20261028/`；光流评分与位姿评分的排序不同，
因此不宣布跨场景、跨指标通用的最好方法。
