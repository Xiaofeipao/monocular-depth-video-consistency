# Part 3 / Direction C：边缘感知细化与边界诊断

## 基本信息与状态

研究问题是：轻量后处理能否在保持米制距离的同时改善深度边界，代价是什么？对Depth Pro和UniDepthV2-S分别比较RAW、RGB/log-depth联合细化C、两个组件消融，以及高斯平滑和RGB Guided Filter两个经典对照；用米制指标、官方SI F1、边缘定位、过渡宽度和纹理区域诊断共同判断效果。

**两模型六方法654图评价、共同案例、诊断表、两份完整诊断核验报告及结果分析均已完成。** 方法不训练，不使用分割模型，不读取另一模型深度或B校准结果；各参数固定，不按测试成绩调整。与[Direction B](stepB.md)独立，不能相加收益。应用与最终交付另见[Step 6](step6.md)。

## 方法与评价协议

### 六种方法

| 方法 | 处理方式 | 参数与比较用途 |
|---|---|---|
| RAW | Part 2原生米制预测，只读引用 | 不增加后处理 |
| C | 空间、RGB颜色与log-depth共同加权，平均逆深度后转回米制 | radius=2（5×5）、σ_rgb=.10、σ_log=.18、σ_space=1.5 |
| C_no_RGB | C去掉RGB权重 | 其余设置与C一致，解释RGB引导作用 |
| C_no_depth_gate | C去掉log-depth门控 | 其余设置与C一致，解释深度门控作用 |
| Gaussian_log | log-depth上高斯平滑，再exp回米制 | 5×5、σ=1.5，普通平滑对照 |
| RGB_guided_log | 彩色RGB Guided Filter作用于log-depth，再exp回米制 | radius=2、ε=.01，经典RGB引导对照 |

C的邻域权重随空间距离、颜色差和log-depth差增大而降低，使用非负权重平均逆深度，不保证恢复基础模型已丢失的细结构。CPU与CUDA使用同一FP32公式，无效位置保持不填洞；本实验输入是完整有限正深度。

RGB Guided Filter采用He、Sun、Tang的彩色局部线性模型，RGB归一化到[0,1]，计算3×3协方差并加ε正则，求解系数后box平均重建，无降采样或ximgproc依赖。[作者资料与论文](https://people.csail.mit.edu/kaiming/eccv10/index.html)

两个经典对照在CPU以float64计算、float32输出，对数域保证正深度；边界采用replicate。它们是独立方法对照，不是C的组件消融：C在逆深度域，经典对照在log-depth域；Guided Filter的两次局部平均使有效支撑可达9×9，不能与5×5核混称相同感受野。两模型使用相同固定参数，经典设置不代表其最优参数。

### 米制与边界协议

输入为Part 2两模型各654份RGB-only、无外部内参的原生米制预测。完整480×640 RGB/深度先处理，再取crop `[45:471,41:601]`；有效GT为`0.001 < GT < 10 m`，课程评分时裁剪预测到该范围，七指标及官方SI Boundary F1逐图等权平均，`alignment:none`。保存的是裁剪前float32米制数组，RAW逐图分数与Part 2冻结表核对。

GT及labels/instances只用于离线评分、选定共同诊断位置，**不输入后处理方法**。三类诊断统一使用未裁剪原生尺度深度，避免将评分裁剪与局部结构变化混淆。

1. **定位与覆盖：**沿用2A log深度边缘定义，深度比阈值1.05/1.10/1.25、匹配容差1/2/3像素，报告P/R/F1、物体标注支持的边缘召回、双向定位距离以及超过3像素的漏边/伪边比例。定位距离以10像素封顶。容差边缘F1与官方SI的定义不同，不能互换。
2. **边界形状：**只从GT/物体标注支持中选择跳变充分、两侧平稳、GT过渡较窄的共同水平/垂直剖面，半径20像素、每图最多3条；报告10–90宽度、中点误差、对比和深度顺序。各自平台归一化只用于形状诊断，不改变米制预测。它不是曲线边界精确法线的估计。
3. **纹理区域：**7×7邻域GT深度比≤1.02、全部有效且距GT 1.05边缘超过3像素；RGB每通道3×3 Sobel除以8，取梯度幅值的通道最大值，≥.05作为纹理区、≤.01作为低纹理对照。统计共同掩码内预测1.05边缘像素比例及深度误差，不把相邻两侧的边缘像素数解释成物理边缘条数。

没有合格区域/物体边缘时保留N/A与覆盖数量，不填0分；弱对比、多重交叉、顺序错误等剖面状态全部保留。宽度比较同时给出各方法可测覆盖、与RAW两两共同可测统计，以及六方法全部可测的共同支持，避免因支持集变化制造优势。纹理指标受filled GT、配准和固定阈值影响，是代理诊断，不是纹理复制的完美真值。

统计按scene成簇、10,000次、seed42抽样，保留图像平均权重；多剖面先图内平均。区间未做多重比较校正，不外推跨域效果。方法与对照的设计受到已查看的测试结果启发，结果属于该划分上的探索性比较；没有按测试结果选择参数或把654图宣称为完全独立的首次确认集。

## 完整运行流程

以下按数据依赖列出完整复现命令，**当前默认产物和诊断报告均已存在，无需重复run**。从项目根目录执行，目录和报告拒绝覆盖；独立重跑使用新的空目录。正式长时间运行由用户启动。

### 1. 检查两模型的原生基线

```bash
./scripts/part3/direction_c.sh check --model depth_pro
./scripts/part3/direction_c.sh check --model unidepth_v2
```

### 2. 生成联合滤波及两个消融预测

```bash
./scripts/part3/direction_c.sh run --model depth_pro --backend cuda
./scripts/part3/direction_c.sh run --model unidepth_v2 --backend cuda
```

运行前检查实际CUDA，保持FP32；CPU时显式改为`--backend cpu`，成本分别报告，不悄悄改变精度或分辨率。这是非学习式处理，不是训练。

### 3. 核验联合滤波与消融公式

```bash
for model in depth_pro unidepth_v2; do
  ./scripts/part3/direction_c.sh verify --model "$model"     --run "outputs/part3/direction_c/$model/evaluation_v1"     --report "outputs/maintenance/part3_studies_verify/${model}_c_filter.json"
done
```

该核验从RAW和RGB使用CPU同公式重做C与两个消融，比较保存数组、GT指标、宏平均和scene统计；CUDA/CPU按`rtol=1e-6, atol=1e-8`核对，不要求逐位一致。这里给出了显式保存报告的完整命令，当前单独报告的留存范围见文末，不将命令示例当作实际执行凭证。

### 4. 经典对照与六方法统一评价

```bash
for model in depth_pro unidepth_v2; do
  ./scripts/part3_studies/direction_c.sh check --model "$model"
  ./scripts/part3_studies/direction_c.sh run --model "$model"
  ./scripts/part3_studies/direction_c.sh verify --model "$model"     --run "outputs/part3/direction_c/$model/diagnostics_v1"     --report "outputs/maintenance/part3_studies_verify/${model}_c_diagnostics.json"
done
```

此阶段在CPU生成两个经典对照、读取共同GT/RGB和C/消融保存预测，统一计算六方法八指标及三类诊断，不重做联合滤波。核验CPU重做经典算子并比较保存数组，再计算全部GT分数、五张CSV和统计；来源/覆盖不一致时停止。

### 5. 独立重跑与小规模检查

复用已有联合滤波/消融预测，单独重算经典对照与统一评价时，指定新目录和报告：

```bash
./scripts/part3_studies/direction_c.sh run --model depth_pro   --output-dir outputs/part3/direction_c/depth_pro/diagnostics_repeat
./scripts/part3_studies/direction_c.sh verify --model depth_pro   --run outputs/part3/direction_c/depth_pro/diagnostics_repeat   --report outputs/maintenance/part3_studies_verify/depth_pro_c_diagnostics_repeat.json
```

接口检查在run上加`--limit 1`并另取空目录，不充当正式结果。若只核验联合滤波公式，也可单独使用步骤3；若完整重新生成C/消融，应在独立项目副本或明确配置引用的新运行目录完成，不能覆盖已绑定来源的数组。

### 为什么它与官方SI F1方向相反

官方实现对相邻像素的**方向性前景/背景关系**，在1.05–1.25的10个阈值上分别计算指标后加权，课程调用还先裁剪预测。容差边缘诊断将各方向合成边缘图，以1/2/3像素容差匹配，且使用未裁剪预测。定义不同，分数不能互换，也不能因结果不一致就修改任一评价器。

三阈值/三容差敏感性对比提供了具体证据：完整C在1.05和1.10阈值下均降低F1，在1.25阈值下则提高F1，且两模型在三种容差下方向一致。下面列1像素容差的差值（完整C−RAW）：

| 模型 | 阈值1.05 | 阈值1.10 | 阈值1.25 |
|---|---:|---:|---:|
| Depth Pro | -0.02687677 | -0.02337748 | +0.03106339 |
| UniDepthV2-S | -0.02707487 | -0.02537302 | +0.01466232 |

这与“较强深度跳变的匹配改善，同时较弱跳变有损失”相符，可帮助解释官方汇总指标的收益，但不是对官方分数进行逐项分解后的因果证明。**应同时报告指标收益和边界覆盖代价，不将SI提高概括成全面锐化。**

## 产物读法、核验与完成范围

`edges_*.png`先显示RGB/GT边缘，再叠加六方法：绿色为1像素容差内匹配的预测边缘，红色为未匹配预测边缘，蓝色为漏GT边缘；它不是语义分割。`texture_*.png`橙色/蓝色分别为共同纹理区/低纹理对照，黑色不参与区域统计，不能仅凭区域掩码判断某方法已产生伪边。
